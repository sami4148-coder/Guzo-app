
# Guzo – Hotel Booking Application

## About the Project

Guzo is a hotel booking application designed to make traveling in Ethiopia easier, faster, and more convenient.

The application connects travelers with hotel owners, allowing users to explore hotels, view photos, check room prices and facilities, and book rooms easily.

## Project Objectives

- Make hotel discovery and booking easier for travelers in Ethiopia.
- Help hotel owners promote their hotels online.
- Provide a convenient platform for communication between travelers and hotel owners.

## Key Features

### For Travelers
- User registration and login.
- Explore hotels and view hotel details.
- View hotel photos, room prices, and facilities.
- Book hotel rooms.
- Contact hotel owners.
- View saved or liked hotels.

### For Hotel Owners
- Register as a hotel owner.
- Submit hotel information for admin approval.
- Post hotel details, photos, prices, and facilities.
- Receive booking requests from travelers.

### For Administrators
- Review and approve hotel owner registrations.
- Manage hotel listings and users.
- Monitor hotel booking activities.
